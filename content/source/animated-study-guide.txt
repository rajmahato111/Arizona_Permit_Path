THE 60-SECOND MEMORY MAP
SIGN SHAPES
Octagon = STOP  Triangle = YIELD  Diamond = WARNING  Pennant = NO PASS
LIGHTS
Flashing red = STOP  Flashing yellow = SLOW + CAUTION  Red arrow = WAIT  Green
arrow = GO
LINES
Yellow center = opposing traffic  Broken yellow = passing when allowed  Double solid yellow
= NO PASS  Broken white = same direction
PARKING
Uphill + curb = wheels left  Downhill = wheels right  Uphill, no curb = wheels right
EMERGENCY /
BUS
Emergency vehicle = move right + stop  School bus stop arm = stop until cleared
VISIBILITY
Fog = low beams  Oncoming high beams = 500 ft  Following high beams = 200 ft
CONTROL
Blowout = no hard braking  Hydroplane = lift accelerator  Skid = steer into skid  Locked
wheels = ease off brakes
LANES / PASSING
Lane change = mirrors + shoulder check  Return after passing when both headlights are
visible
Study trick: Read the question, cover the green answer with your hand, answer out loud, then check the card. Repeat any card you miss twice.
